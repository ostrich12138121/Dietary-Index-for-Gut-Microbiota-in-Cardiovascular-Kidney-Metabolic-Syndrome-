## Data source

The raw data used in this study are publicly available from the **National Health and Nutrition Examination Survey (NHANES)**

Because NHANES data are publicly available but distributed by survey component and cycle, raw data files are **not included** in this repository. Users should download the original NHANES files and place them in the designated data folder before running the scripts.
